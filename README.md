# GD Menu

Небольшой внутренний мод для Geometry Dash 2.209 (Windows, x64) с меню на Dear ImGui.
Сейчас умеет: **Noclip**.

## Как это работает

- `proxy.cpp` — прокси для `XInput1_4.dll`. Игра (`libcocos2d.dll`) подгружает эту DLL
  из своей папки и вместе с ней запускает мод. Вызовы XInput пересылаются настоящей
  системной DLL, поэтому геймпад продолжает работать. Номера экспортов совпадают с
  системной DLL (игра импортирует `XInputGetState` по номеру 2).
- `dllmain.cpp` — сам мод: хук `wglSwapBuffers` (рисует меню через ImGui + OpenGL3) и хук
  `PlayLayer::destroyPlayer` (noclip) на MinHook.
- `build.bat` — скачивает ImGui и MinHook, собирает DLL и копирует её в папку игры.
- `diag.bat` — собирает диагностику (импорты/экспорты DLL) в `diag.txt`.

## Установка

1. Нужна Visual Studio 2022 с нагрузкой «Разработка классических приложений на C++».
2. Положи `build.bat`, `dllmain.cpp`, `proxy.cpp` в одну папку, закрой игру и запусти:

   ```
   build.bat
   ```

   Если игра не в стандартной папке Steam, укажи путь:

   ```
   build.bat "D:\Games\Geometry Dash"
   ```

3. Запусти игру. **INSERT** — показать/скрыть меню.

## Удаление

Удали `XInput1_4.dll` из папки игры (файлы игры не изменяются). Журнал мода — `GDMenu.log`
в той же папке, его тоже можно удалить.

## Обновление игры

Смещения сейчас для версии 2.209 (`dllmain.cpp`):

```cpp
namespace offsets {
    constexpr uintptr_t PlayLayer_destroyPlayer = 0x512390; // RVA = адрес в Ghidra - 0x140000000
}
```

Рядом хранятся первые байты функции (`k_destroyPrologue`). Если после обновления они не
совпадают, мод покажет предупреждение, noclip отключится, а меню продолжит работать.
Тогда нужно заново найти `destroyPlayer` в Ghidra (через ссылки на строку `explode_11.ogg`
и вызывающую функцию), обновить RVA и байты и пересобрать.

## Добавление функций

1. Поле в структуре `Settings`.
2. Хук в `setupHooks()` (по образцу `h_destroyPlayer`).
3. Галочка или слайдер в `drawMenu()`.

## Диагностика

- Меню нет: смотри `GDMenu.log` в папке игры (видно, поставились ли хуки и отрисовался ли кадр).
- Ошибка «порядковый номер не найден» при запуске: запусти `diag.bat` и сравни экспорты
  прокси с системным `XInput1_4.dll`.

## Важно

Мод только для одиночной игры и экспериментов. Прохождения с noclip нельзя отправлять
на рейт и в лидерборды: за это банят.
